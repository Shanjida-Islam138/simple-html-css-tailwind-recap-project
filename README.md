## Overview

This project was developed as a practice task assigned by **Programming Hero**. The main goal was to practice Tailwind CSS, responsive layouts, positioning, and multi-column grid structures.

The website includes a complete tea brand landing page with a hero section, featured products, tea information, client reviews, news and events, and a responsive footer.

<br>

## Key Features

- **Overlapping UI Elements:** Created layered client testimonial cards using absolute positioning and z-index.
- **Grid & Flex Layouts:** Used CSS Grid and Flexbox to structure product cards, news cards, and other sections.
- **Responsive Design:** Added responsive layouts for different screen sizes using Tailwind CSS.
- **Clean UI:** Focused on spacing, alignment, typography, and a consistent visual design.

<br>

## Project Status

- Responsive design completed for the main sections including Banner, Featured Products, Client Reviews, and News & Events.
- Further improvements and mobile optimization may be added in the future.
