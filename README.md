# Tea House - Landing Page

A modern landing page concept for a tea brand, built using HTML5 and Tailwind CSS.

![Tea House Landing Page Preview](https://github.com/Shanjida-Islam138/simple-html-css-tailwind-recap-project/blob/15b35a1fbb954ecc28686dc9f252ab257e4c877e/Tea-house-landing-page.jpeg)

## Overview
This project was developed as a practice layout to master complex CSS positioning, Tailwind utility classes, and multi-column grid structures. It features a complete brand UI—including a hero section, product showcase, layered client review section, and news updates.
